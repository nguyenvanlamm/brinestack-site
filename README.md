# brinestack-site

Trang giới thiệu, chính sách riêng tư và hỗ trợ của game iOS **Brinestack** (repo game: nguyenvanlamm/brinestack).
GitHub Pages phục vụ thẳng từ nhánh `main` (không có workflow): https://nguyenvanlamm.github.io/brinestack-site/

- `index.html`: trang giới thiệu (tiếng Anh)
- `privacy.html`: Privacy Policy URL cho App Store Connect
- `support.html`: Support URL cho App Store Connect
- `assets/`: icon và ảnh chụp màn hình lấy từ repo game (`screenshots/`, `design-demos/logo/`)
- `robots.txt`, `sitemap.xml`, `llms.txt`: cho máy tìm kiếm và bot AI (robots.txt thật nằm ở gốc host, repo `nguyenvanlamm.github.io`; bản ở đây ghi lại chính sách)
- `index.html.md`, `privacy.html.md`, `support.html.md`: bản Markdown của từng trang cho bot AI; sửa trang HTML thì sửa luôn bản `.md`
- `assets/share-card.jpg`: ảnh chia sẻ 1200x630 (Open Graph/Twitter), dựng từ `screenshots/dive.png`, `screenshots/restack.png` và icon của repo game
